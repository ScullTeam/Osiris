## ✨ Возможности

- ⚡ Быстрый запуск Unlock промптов на любой странице
- 🌐 Поддержка: **DeepSeek, Grok, Kimi, Qwen, Gemini, Z.ai** и других AI в будущем
- 🎨 Современный и удобный интерфейс
- 🔄 Автоматическая проверка обновлений (при запуске браузера + ручная кнопка)
- 🛡️ Закрытый код

## 📥 Установка

### Способ 1 — Рекомендуемый (через .zip)
1. Скачай последний релиз (`Osiris_vX.X.X.zip`)
2. Распакуй архив в удобную папку
3. Открой страницу `chrome://extensions/`
4. Включи **«Режим разработчика»** (в правом верхнем углу)
5. Нажми **«Load unpacked»** и выбери распакованную папку или Перетащи файл `Osiris_vX.X.X.zip` на страницу `chrome://extensions/`

### Способ 2 — Через .crx
Перетащи файл `Osiris_vX.X.X.crx` на страницу `chrome://extensions/`

> **Важно**: Расширение работает только в распакованном виде или через .crx. Установка из Chrome Web Store пока недоступна.

## 🔄 Обновления

Расширение автоматически проверяет наличие новых версий:
- При запуске браузера
- По кнопке **«Проверить обновления»** в popup
